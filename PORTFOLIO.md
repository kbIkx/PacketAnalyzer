# Portfolio descriptions

## English

PacketAnalyzer is a Windows network traffic analysis app built with Python, Scapy and PySide6. It supports live capture, background PCAP loading, packet inspection, display filters, traffic charts, observed TCP flows, and PCAP/CSV export. The analysis core remains usable from a CLI and is covered by synthetic packet tests and Windows CI.

## Русский

PacketAnalyzer — приложение для анализа сетевого трафика на Windows, написанное на Python, Scapy и PySide6. Оно умеет захватывать пакеты, открывать PCAP в фоне, показывать структуру пакета, фильтровать метаданные, строить графики трафика, отслеживать наблюдаемые TCP-потоки и экспортировать PCAP/CSV. Консольный режим сохранён; core проверяется синтетическими пакетами и тестами в Windows CI.
